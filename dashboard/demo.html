DEMO CONTROLS Gate crossings and reachability changes are synthetic — Nokia's sandbox cannot move a device. Everything downstream of the trigger is real: Location Retrieval, Congestion Insights, QoD and Device Reachability run against the live sandbox, with the latencies shown below.

1 · Set up a crossing

Clears the database, enrols the demo traveller, and arms both geofences on the network for real.

2 · Drive the crossing

Each button is one synthetic network event. Nothing here decides what happens next — the state machine and the agent do.

3 · Move the clock

Virtual clock — the same one run_demo.py advances. A crossing takes over an hour in real time.

—

4 · Humans answer

The two replies that stop an escalation: the traveller answering the Tier 0 ping, and the contact standing the alarm down after Tier 1.
